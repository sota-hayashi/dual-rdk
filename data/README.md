# data/ — 入力データ（読み取り専用）

このディレクトリ配下は解析の**入力**であり、コード実行によって変更してはならない。
全パスは `config.py` の定数（`ONLINE_DATA_DIR` 等）経由で参照する。

## データセット一覧

| ディレクトリ | 旧名 | 形式 | 件数 | 内容 |
|---|---|---|---|---|
| `raw/pilot_csv/` | `data00/` | CSV | 4 | 対面パイロット実験（2025年11月収集、`experiment_data_YYYYMMDDHHMM.csv`） |
| `raw/pilot_json/` | `data01/` | JSON | 19 | パイロット実験（1被験者=1ファイル、ファイル名は被験者ID） |
| `raw/online/` | `data_online_experiment/` | JSON | 80 | オンライン本実験（Prolific、80名。1被験者=1ファイル） |
| `excluded/` | `data_excluded/` | JSON | 4 | 本実験データから物理的に除外したファイル（テスト実施分 `sota20260305.json` を含む） |

## 除外基準について

被験者の除外は2段階で管理されている。

1. **ファイルレベル除外**: 解析対象外のファイル（動作テスト等）は `excluded/` に移動され、`raw/online/` には含まれない。
2. **ロード時除外**: 色バイアス・task-irrelevant 試行数などの行動基準による除外は、`config.py` の `EXCLUDED_SUBJECTS`（被験者IDリスト、除外理由をコメントで併記）で定義され、ロード処理で適用される。

## 運用ルール

- 新しいデータは `raw/` 配下に収集フェーズが分かる名前でディレクトリを切り、この README に1行追記する（要件定義書 §7-4）。
