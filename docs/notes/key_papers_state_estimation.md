# 「まず読む」論文の要約 ― 隠れ状態推論と信念状態

本ノートは [`../methods/state_estimation_primer.md`](../methods/state_estimation_primer.md) の6節「**まず読む（本研究に直結）**」で挙げた3本を，本研究（dual-RDK 課題の暗黙的な報酬構造学習）への含意まで含めて要約する．3本に共通するメッセージは一つ：

> **脳（あるいはその計算モデル）は，観測が曖昧なとき「今どの隠れ状態にいるか」の確率分布＝信念状態を推論し，その信念のうえで価値・報酬予測誤差を計算している．** 明示的にラベルを与えられなくても，経験から潜在レジームを推し量る ―― これが本研究の「暗黙的学習」の理論的な受け皿になる．

ベイズフィルタ・信念状態そのものの概念は姉妹ノート [`bayes_filter_primer.md`](bayes_filter_primer.md) を参照．

## 1. Starkweather, Babayan, Uchida & Gershman (2017)
### *Dopamine reward prediction errors reflect hidden-state inference across time.* Nature Neuroscience 20(4):581–589.

**一言で：** ドパミンの報酬予測誤差（RPE）は，単に「時刻」を追っているのではなく，**「今どの隠れ状態にいるか」の推論（belief state）** を反映している，ということを生理実験で示した論文．

**課題設定．** マウスに古典的条件づけ．嗅覚キューの後，可変の遅延を経て報酬が来る．2種類のタスクを比較する：
- **Task 1**：キューの後は **必ず** 報酬が来る（報酬省略なし）．
- **Task 2**：キューの後，**一定確率で報酬が来ない（省略）試行** が混ざる．

Task 2 では，時間が経っても報酬が来ないとき，動物は「まだ来ていないだけ（報酬あり状態）」なのか「今回は省略（報酬なし状態）」なのかを **区別できない**．この区別は隠れ状態であり，時間経過とともに信念を更新して推し量るしかない．

**中心的発見．** 報酬到来時のドパミン応答（＝RPE）の大きさを，キューからの遅延の関数として見ると，**2つのタスクで逆向きの依存性** を示した．遅延に対して応答が Task 1 では一方向に，Task 2 では反対方向に変化する ―― この違いは「経過時間そのもの」だけを表現する古典的 TD モデル（complete serial compound 的な時間表現）では説明できない．

**方法とモデル．** VTA のドパミンニューロンを記録．隠れ状態上の信念（belief state）を状態表現として持つ **belief-state TD モデル** を組むと，両タスクの遅延依存性を同時に再現できた．一方，信念を持たない時間表現の TD モデルでは再現できなかった．

**本研究への含意．**
- 「報酬構造が隠れていて，観測（試行の経過・結果）から推論するしかない」という本課題の構造は，まさにこの論文の枠組みそのもの．
- RPE や価値を **信念状態のうえで** 計算する，という設計思想（belief-MDP）を，神経実装レベルで支持する一次文献として引ける．
- primer の Route B（ベイズフィルタで $b_t$ を推定し $Q(b_t,a)$ で行動する）を正当化する中核引用になる．

## 2. Gershman, Blei & Niv (2010)
### *Context, learning, and extinction.* Psychological Review 117(1):197–209.

**一言で：** 学習とは **「観測を生み出している潜在原因（latent cause）を推論すること」** だと捉える理論．消去（extinction）は「学んだことを消す」のではなく「**新しい潜在原因を推論する**」ことだと説明する．

**中心的アイデア．**
- 動物は，感覚入力（キュー・文脈・報酬）が **いくつかの潜在原因** によって生成されていると仮定し，各試行がどの原因に属すかを **ベイズ的にクラスタリング** しながら学習する．
- 潜在原因の数はあらかじめ決めない．**ノンパラメトリックベイズ（中華料理店過程／ディリクレ過程混合）** の事前分布を使い，「新しい原因が必要か」もデータから推論する．必要になれば原因を1つ増やす．

**説明できる現象．** 消去後に反応がぶり返す一連の現象 ―― **自発的回復（spontaneous recovery）・更新効果（renewal）・復元（reinstatement）** ―― を統一的に説明する．獲得フェーズと消去フェーズが **別々の潜在原因** に割り当てられるため，消去は元の原因の連合を上書き（unlearn）せず，元の原因が再活性化すれば反応が戻る．獲得を緩やかにするか一気にやるか（漸進的 vs 急激）や文脈の効果も，原因の推論として説明される．

**本研究への含意．**
- 本課題の「白高／黒高」というブロックごとに切り替わる報酬レジームは，まさに **潜在原因（＝潜在レジーム）** として定式化できる．参加者はラベルを与えられずに，どのレジームにいるかを推論している．
- レジームの **切り替わり（新しい原因への乗り換え）** をどうモデル化するか，という設計のテンプレートになる（cf. ハザード率・ボラティリティ；primer 3(C) の Behrens 2007）．
- 「気づきの有無」を，潜在原因の分離の鋭さや，新しい原因への乗り換えの速さとして操作化できる可能性を示唆する．

## 3. Wilson, Takahashi, Schoenbaum & Niv (2014)
### *Orbitofrontal cortex as a cognitive map of task space.* Neuron 81(2):267–279.

**一言で：** 眼窩前頭皮質（OFC）の役割を，「報酬価値を計算する場所」ではなく，**「課題の状態空間の認知地図 ―― とりわけ観測からは直接見えない隠れ状態を表現する場所」** だと提案する理論・総説論文．

**中心的主張．**
- OFC は，強化学習における **状態表現（state representation）** を担う．価値そのものというより，価値や RPE を計算する土台となる「今，課題のどの状態にいるか」を供給する．
- 特に OFC が本質的に必要になるのは，**知覚的には区別できないが，隠れた情報によって意味が異なる状態** を扱うとき ―― すなわち **部分観測（partial observability）** の場面である．現在の感覚入力だけでは同じに見える2状況を，文脈や履歴から推論して切り分ける役割．
- 従来ばらばらに語られてきた OFC の諸機能（報酬・逆転学習・信用割当など）を，「隠れ状態を含む課題状態空間の地図」という一枚の視点で統合する．

**本研究への含意．**
- 本課題の「白高／黒高」は，**同じ刺激（ドット運動）を見ていても報酬構造が異なる** という，まさに「知覚的に区別できない隠れ状態」の典型例．OFC 認知地図の枠組みにそのまま乗る．
- 「観測（角度）と状態（隠れレジーム）を分け，状態は推論して供給する」という primer の主張（3節・4節）に，神経基盤の裏付けを与える．
- 信念状態 $b_t$ を「課題状態空間上の現在地の分布」と読み替える解釈を支える引用になる．

## 4. 3本を本研究にどう使うか（統合メモ）

| 論文 | 提供するもの | 本研究での使いどころ |
|---|---|---|
| Starkweather 2017 | 信念状態上で RPE を計算する神経実装の実証 | Route B（$Q(b_t,a)$）の正当化・中核引用 |
| Gershman, Blei & Niv 2010 | 潜在原因（レジーム）推論の計算枠組み | 隠れパターン $z$ の定式化・レジーム切替のモデル化 |
| Wilson 2014 | 隠れ状態を含む課題状態空間の認知地図（OFC） | 「観測≠状態」「状態は推論で供給」の神経基盤 |

**共通の骨子：** 3本とも「観測が曖昧なら，脳は隠れ状態の確率分布（信念）を推論し，そのうえで価値・誤差・行動を計算する」と述べている．本研究の「暗黙的学習」は，この **信念状態の緩やかな更新** として定量化できる ―― 明示ラベルなしにレジームを推し量る営み，という primer 3(C)・4節の主張の一次文献群である．
