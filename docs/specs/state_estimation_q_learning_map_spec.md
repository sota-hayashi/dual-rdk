# 状態を観測から推定するQ学習モデル 仕様書（MAP推定）

本仕様書は，[`state_estimation_primer.md`](state_estimation_primer.md) の概念整理を受けて，**隠れ報酬パターンをオラクルとして渡さず，観測（各刺激の運動方向・画像）から状態を扱う**Q学習モデルを具体的な数式・疑似コードで定義する．

`q_learning_ooz_map.py` が抱える矛盾 ―― 状態 `target_item`（真の白高／黒高パターン）を正解として与えている ―― を，状態推定の枠組みで解消することを目的とする．

3つの道を提示する：

| ルート | 状態の扱い | 円環性の解決 | index 問題の解決 | 既存実装との関係 |
|---|---|---|---|---|
| **A. 観測を状態とする関数近似** | 観測角度 $\theta$ をそのまま状態入力に | 周期基底 $\phi(\theta)$ | 表を引かず $Q(\theta,a)=w_a^\top\phi(\theta)$ | **既に `directional_q_learning_map.py`** |
| **B. 報酬を生む方向の状態推定** | 潜在「報酬が出る方向 $\psi_c$」を円環上のベイズフィルタで推定 | 潜在自体が円環上の連続量 | index は $\psi$ のグリッド，価値は信念から直接導く | `state_estimation_q_learning_map.py` を改修 |
| **C. 知覚的状態推定（補）** | ノイズあるドットから真方向を推定 | 円環カルマン／von Mises 測定モデル | ― | 拡張オプション |

本研究の中心的主張（暗黙学習）に最も忠実なのは **Route B**．Route A は既に実装済みで識別性も高い実務的第一歩．以下，各ルートの数式を与える．

> **改訂履歴（2026-08-06）**：初版の Route B は潜在を離散2値の色レジーム $z\in\{W,B\}$ とし，ハザード率 $h$ で遷移させる設計（旧 B-i）だった．実データ検証の結果これは構造的に成立しないことが判明したため（§B.1），**潜在を「報酬が出る方向 $\psi$」に置く設計（旧 B-ii）を本仕様の主軸に据え直した**．旧 B-i の記述は §B.1 に棄却理由として残す．

## 記号と共通設定

各試行 $t$ で：

- $o_t = (\theta_{w,t}, \theta_{b,t})$：白・黒ドット群の運動方向（ラジアン，$[0,2\pi)$）．観測．
- $a_t \in \{\text{white}, \text{black}\}$：参加者が報告した方向がどちらの色の運動方向に近かったか（`chosen_color`）．
- $\theta_{\text{rep},t}$：報告方向（**`response_angle_rdk`**，ラジアン）．
- $r_t \in [0,1]$：スカラー報酬（`reward_points`/10）．**二値ではなく角度精度で連続に変化する**（§B.1 の注意）．
- $\psi_c \in [0,2\pi)$：**色 $c$ を報告すると報酬が出る方向**．潜在，セッション内で不変．**モデルには渡さない**（＝推定対象）．
- `target_group` / `session_rotation` は事後分析と規範ベンチマーク（§B.10）でのみ使用．行動モデルの学習・選択には渡さない．

前処理は既存モデルと共通（`rt`/`chosen_color` の NaN を drop，度→ラジアン，報酬を $[0,1]$ に）．

> **報告角のフレームに関する注意**：$\theta_{\text{rep}}$ には必ず `response_angle_rdk` を使う．`response_angle_css` は $(450^\circ - \theta_{\text{rdk}}) \bmod 360^\circ$ の**鏡映座標**であり，刺激方向カラム（`target_direction` / `distractor_direction`，RDK フレーム）と混在させると価値の更新位置が円環上の鏡像に置かれる．実データでの中央値 $|\theta_{\text{rep}} - \theta_{\text{target}}|$ は rdk フレームで $27^\circ$，css フレームで $90^\circ$．既存の `directional_q_learning_map.py` と `von_mises_value_learning_map.py` は css を使っており，要修正．

# Route A：観測角度を状態とする関数近似Q学習

## A.1 位置づけ

**これは既存の `directional_q_learning_map.py` がすでに実装している道**である．本節はそれを「状態推定」の言葉で読み直し，円環性と index 問題がどこで解けているかを明示する．新規実装は不要（既存を使えばよい）．

## A.2 状態表現：周期基底による符号化

生の角度を離散キーにする代わりに，$N$ 個の von Mises 基底で符号化する：

$$\mu_j = \frac{2\pi j}{N},\quad \phi_j(\theta)=\exp[\kappa\cos(\theta-\mu_j)],\quad \boldsymbol{\phi}(\theta)=[\phi_0,\ldots,\phi_{N-1}]^\top$$

$\phi(\theta+2\pi)=\phi(\theta)$ なので **円環性はここで解決**（primer §5-1）．

## A.3 価値・選択・更新

色ごとの重み $\mathbf{W}_c\in\mathbb{R}^N$ で価値を表現（**index は連続角度でなく重みベクトル**なので primer §5-2 の index 問題も解決）：

$$V_c(\theta) = \mathbf{W}_c\cdot\boldsymbol{\phi}(\theta)$$

$$dq = \beta\big[V_{\text{black}}(\theta_b) - V_{\text{white}}(\theta_w)\big] + c_{\text{black}},\qquad P(\text{black}) = \sigma(dq)$$

$$\delta_t = r_t - V_{a_t}(\theta_{\text{rep},t}),\qquad \mathbf{W}_{a_t} \leftarrow \mathbf{W}_{a_t} + \alpha_t\,\delta_t\,\boldsymbol{\phi}(\theta_{\text{rep},t})$$

学習率は OOZ ラベルで切り替え（$\alpha_t=\alpha_0$ if $z^{\text{ooz}}_t=0$ else $\alpha_1$）．パラメータ $(\alpha_0,\alpha_1,\beta,c_{\text{black}})$，事前分布・推定手続きは既存 spec と同一．

> **要点**：Route A では「状態推定」は明示的には行わない．観測をそのまま特徴に通して価値関数を学ぶだけである．暗黙学習の *矛盾（オラクル問題）* は解けているが，**「報酬が出る方向についての不確実性を保持し，それを絞り込んでいく」という過程そのものはモデル化していない**（信念も，その信頼度も出てこない）．それを正面から扱うのが Route B．なお Route A の $\mathbf{W}_c$ と Route B の $b(\psi_c)$ はどちらも「どの方向が価値を持つか」を表す円環上の関数であり，違いは**不確実性を明示的に持つかどうか**と，**構造の仮定（払う方向が1つある）を置くかどうか**にある．

# Route B：報酬が出る方向を推定するQ学習（本仕様の主眼）

## B.1 潜在を「色レジーム」ではなく「方向」に置く理由

初版は潜在を離散2値の色レジーム $z_t\in\{W,B\}$ とし，ハザード率 $h$ で遷移させ，**報酬履歴だけ**で信念を更新する設計だった（旧 B-i）．これは実データ（online 61名，learning phase 2928試行）で以下の通り成立しないことが確認された．

**(1) 追跡すべき時間的持続性が存在しない．** `index.html` は2条件×24回を `jsPsych.randomization.shuffle` で完全ランダム化しており，ブロック構造が無い．実データでの試行間切替率は $0.532$，$I(z_t; z_{t-1}) = 0.003$ bit．つまり $z$ の系列はほぼ i.i.d. で，前試行の状態は今試行の状態を予測しない．$h \approx 1/(\text{平均ブロック長}) $ という固定方針は前提から誤りである．

**(2) 対称初期化が代数的な不動点になる．** 仕様どおり $q=[[0.5,0.5],[0.5,0.5]]$，$b_0=(0.5,0.5)$ で始めると，$q(W,a)=q(B,a)$ ゆえ尤度が $\text{lik}_W=\text{lik}_B$ となり補正が効かず，$b$ が一様なら $(1-h)\cdot 0.5 + h\cdot 0.5 = 0.5$ で**任意の $h$ について** $b^-=(0.5,0.5)$．責任がどちらも $0.5$ なので2つのレジーム行に同一の更新が入り，永久に区別が生まれない．実測でも $h=0.5/0.3/0.1/1{:}48$ の4条件で出力が完全一致し，$b^-$ の試行内 SD は $0.000000$，最終 $q$ の2行は同一（$[[0.436,0.452],[0.436,0.452]]$）だった．**$h$ の選び方の問題ではなく，$h$ を含む尤度が厳密に平坦になる**．

**(3) 対称性を破っても選択に使える信念は得られない．** $q=[[0.7,0.3],[0.3,0.7]]$ で初期化するとフィルタは動くが，真の状態との相関は補正後 $b_t$ が $+0.82$（＝報酬を見た**後**なら当てられる＝回顧的）である一方，**因果的に選択へ使える予測信念 $b_t^-$ は $-0.07$（$h=0.2$），$-0.09$（$h=1/48$）と負**になる．24/24 の非復元シャッフルゆえ系列がわずかに反持続的で，持続性を仮定するフィルタは chance より悪い．$p(\text{target})$ はどの $h$ でも前半 $0.49\to$ 後半 $0.48$ で学習が生じない．

**(4) 課題の行動・報酬が二値ではない．** 実際の行動は円環上の連続角度であり，色ラベルへの二値化で $4.5\%$（133試行）が「どちらの方向からも $45^\circ$ 超」として捨てられる．報酬も二値ではなく，色が正しい試行だけを見ても $1$–$10$ 点に連続的に散らばる（平均 $6.95$，SD $2.14$，$|\text{AE}|$ 平均 $13.2^\circ$，SD $10.6^\circ$）．**報酬関数は角度精度でできている**（$10(1-|\text{AE}|/50)$）のに，二値行動モデルはその次元を丸ごと捨てる．

**(5) $\{W,B\}$ というカテゴリ構造自体が実験者側の再記述である．** 教示は「ドット数が多く見える方の運動方向を答えよ」であり，「白か黒を選んで報酬を得よ」ではない．参加者が持っていないのは正解ラベルだけでなく，「2つのレジームがある」という枠組みそのものである．オラクル状態を渡さないようにしても，カテゴリ構造を渡していれば同種の矛盾が残る．

> **結論**：潜在は「色のレジーム」ではなく，**参加者が経験から直接形成しうる量**に置く．すなわち「**どの方向に答えると点が入るか**」である．これは（a）セッション内で不変なのでハザード率が不要，（b）テンプレートの存在を知らなくても報酬経験から形成できるので心的主張として無理がない，（c）報酬が連続量であることを尤度としてそのまま使える．

> **潜在をセッション回転 $r$ に置かない理由**：$r$ は「どの方向が払うか」と1対1に対応するが，参加者はテンプレートの存在自体を知らないため，$r$ の信念を保持しているという主張は心的に不当である．$r$ を潜在とする定式化は**規範ベンチマーク（§B.10）に限って**用い，行動モデルには持ち込まない．

## B.2 生成モデルの設定

各色 $c\in\{\text{white},\text{black}\}$ について，潜在

$$\psi_c \in [0,2\pi)\quad:\quad \text{色 } c \text{ の運動方向がこの付近のとき，それを報告すると報酬が出る}$$

を置く．$\psi_c$ は**セッション内で不変**（実験デザイン上，高報酬帯はセッション回転で固定される）．したがって遷移モデル＝恒等写像であり，$h$ は不要．忘却を入れたい場合のみ §B.6 の $\epsilon$ を使う．

エージェントに与えない構造：
- 白と黒の高報酬帯が $90^\circ$ 離れているという関係（参加者は知らない）．$b(\psi_{\text{white}})$ と $b(\psi_{\text{black}})$ は**独立**に保持する．
- 高報酬帯の幅（$45^\circ$）．般化幅 $\kappa_g$ は §B.3.1 で定義し既定値は §B.6 で与える．

## B.3 観測モデル：報酬の生成過程を明示的に書く

信念更新の前に，**「潜在 $\psi$ が与えられたとき，その試行の報酬 $r_t$ がどう生成されるか」**を確率分布として定義する．これが尤度であり，ベイズフィルタの補正ステップの中身になる．

### B.3.1 「その色が払うか」の確率

色 $c$ の運動方向 $\theta_{c,t}$ が潜在 $\psi_c$ の近傍にあるほど，その色を報告すれば払われる：

$$p^{\text{pay}}_c(\psi) \;=\; \exp\!\big[\kappa_g\big(\cos(\theta_{c,t}-\psi) - 1\big)\big] \;\in\; (0,1]$$

$\Delta=0$ で $1$，離れるほど $0$ に近づく．$\kappa_g$ は**参加者が仮定する般化幅**であり，課題の真の帯幅 $45^\circ$ は与えない（既定 $\kappa_g=4$，半値幅 $\approx34^\circ$）．

### B.3.2 払われた場合／払われなかった場合の報酬

報酬則は $r = \max(0,\,1-|\text{AE}|/50^\circ)$（`index.html` の `reward_points/10`）である．参加者は「報告が正解方向に近いほど点が高い」ことを試行を通じて体験しているので，この形を知っていると仮定する（**テンプレートの幾何は仮定しない**）．

- **色 $a_t$ が払う場合**：正解方向は $\theta_{a_t,t}$ なので

$$\hat r^{\text{pay}}_t \;=\; \max\!\big(0,\; 1 - |\theta_{\text{rep},t}-\theta_{a_t,t}|/50^\circ\big)$$

- **色 $a_t$ が払わない場合**：正解方向はもう一方であり，2方向は $90^\circ$ 以上離れているので報酬は $0$．実データでもこのセルの平均報酬は厳密に $0.000$（§B.1(4) の集計）：

$$\hat r^{\text{nopay}}_t \;=\; 0$$

**重要**：$\hat r^{\text{pay}}_t$ と $\hat r^{\text{nopay}}_t$ は**観測済みの角度だけから計算でき，$\psi$ に依存しない**．$\psi$ 依存性は $p^{\text{pay}}(\psi)$ ただ一つに集約される．

### B.3.3 尤度

したがって報酬の条件付き分布は2成分混合になる：

$$P(r_t \mid \psi,\, o_t,\, \theta_{\text{rep},t}) \;=\; p^{\text{pay}}_{a_t}(\psi)\; \mathcal{N}_{[0,1]}\!\big(r_t;\, \hat r^{\text{pay}}_t,\, \sigma_t^2\big) \;+\; \big(1-p^{\text{pay}}_{a_t}(\psi)\big)\; \mathcal{N}_{[0,1]}\!\big(r_t;\, 0,\, \sigma_t^2\big)$$

$\mathcal{N}_{[0,1]}$ は $[0,1]$ 上の切断正規分布（$r_t$ について正規化されている＝**正規の尤度**）．

$\sigma_t$ は**参加者が報酬と自分の報告角度の関係をどれだけ正確に追えているか**を表す．報酬則の知識の粗さ，運動方向の知覚ノイズ，報告のブレがすべてここに吸収される．$\sigma_t\to 0$ で理想観測者（§B.10，3試行で同定）に一致し，$\sigma_t$ が大きいほど学習が遅くなる．**つまり $\sigma_t$ が本モデルにおける「最適からの隔たり」の唯一のつまみであり，旧仕様の学習率 $\alpha$ に対応する量である．**

OOZ ラベルで切り替える：$\sigma_t=\sigma_0$ if $z^{\text{ooz}}_t=0$ else $\sigma_1$．OOZ（RT が速くかつ逸脱している＝ゾーン外）の試行では結果から情報を汲み取りにくい，という仮説を $\sigma_1>\sigma_0$ として検定できる．

## B.4 信念更新（円環グリッド上のベイズフィルタ）

$\psi$ を $M$ 分割（既定 $M=360$）したグリッドで表現し，初期信念は**一様** $b_0(\psi)=1/M$（どの方向が払うか全く知らない）．

**(i) 予測ステップ**：$\psi_c$ はセッション内で不変なので遷移は恒等写像であり，$b^-_t = b_{t-1}$．忘却 $\epsilon>0$ を入れる場合のみ

$$b^-_t(\psi) = (1-\epsilon)\,b_{t-1}(\psi) + \epsilon/M$$

**(ii) 補正ステップ**：§B.3.3 の尤度でベイズ更新する（**報告した色 $a_t$ の信念のみ**）：

$$b_t(\psi) \;=\; \frac{P(r_t\mid\psi,\cdot)\; b^-_t(\psi)}{\sum_{\psi'} P(r_t\mid\psi',\cdot)\; b^-_t(\psi')}$$

実装は対数領域で行う（数値安定化のため．モデルの内容は上式と同一）：

$$\log b_t(\psi) \;=\; \log b^-_t(\psi) \;+\; \operatorname{logaddexp}\!\Big(\log p^{\text{pay}}(\psi) + \log A_t,\;\; \log\big(1-p^{\text{pay}}(\psi)\big) + \log B_t\Big) \;-\; \log Z_t$$

$$A_t = \mathcal{N}_{[0,1]}(r_t;\hat r^{\text{pay}}_t,\sigma_t^2),\qquad B_t = \mathcal{N}_{[0,1]}(r_t;0,\sigma_t^2)$$

$A_t, B_t$ は $\psi$ に依らない定数なので，1試行あたりの計算は長さ $M$ のベクトル演算1回で済む．

尤度は $p^{\text{pay}}(\psi)$ について**線形**（$L(\psi) = B_t + p^{\text{pay}}(\psi)(A_t-B_t)$）なので，挙動は直感的である：

- 報酬が高い（$r_t \approx \hat r^{\text{pay}}_t$）→ $A_t \gg B_t$ → $p^{\text{pay}}$ が大きい $\psi$ が支持される → 信念が $\theta_{a_t}$ に**引き寄せられる**
- 報酬が $0$ → $B_t \gg A_t$ → $p^{\text{pay}}$ が小さい $\psi$ が支持される → 信念が $\theta_{a_t}$ から**押しのけられる**

> **旧 B-i との決定的な違い**：一様事前は**不動点ではない**．$L(\psi)$ が $\psi$ の非定数関数である限り，最初の試行から信念は一様を離れる．B-i を殺した §B.1(2) の対称固定点はここでは構造的に発生しない．

**選んでいない色の信念は更新しない．** 「参加者が直接経験したのは報告した方向についてだけ」という最小の仮定である．結果として色バイアスの強い参加者は非選択色について学習が進まないという予測が出る（検証可能）．排他性（片方が払うならもう片方は払わない）を仮定する拡張は §B.11 に置く．

## B.5 選択

信念から，**その試行で色 $c$ の方向を報告したら払われる確率**を作る（$\psi$ を周辺化）：

$$\pi_c(t) \;=\; \sum_{\psi} b^-_t(\psi)\; p^{\text{pay}}_c(\psi) \;\in\;(0,1]$$

離散レジーム $z$ を仮定せずに，**それと同じ役割を果たす量が信念から導かれる**点が本設計の要である．

選択則（符号規約は既存モデルと統一，$c_{\text{black}}>0$ が黒選好）：

$$dq = \beta\big[\pi_{\text{black}}(t) - \pi_{\text{white}}(t)\big] + c_{\text{black}},\qquad P(\text{black}\mid t)=\sigma(dq)$$

> **因果の注意（旧仕様から継承）**：選択に使うのは報酬観測**前**の信念 $b^-_t$．報酬を見てから $b_t$ に補正し，次試行へ渡す．

正解色を報告したときの期待報酬（$\approx 0.7$）は $\pi_c$ の係数として入るが，差分を取ると $\beta$ に吸収されるので明示的なパラメータにはしない．

## B.6 パラメータと事前分布

| パラメータ | 範囲 | 意味 | 事前分布 |
|---|---|---|---|
| $\sigma_0$ | $(0,\infty)$ | 非OOZ 試行の報酬予測精度（小さいほど速く学習） | $\text{Gamma}(2,0.3)$ |
| $\sigma_1$ | $(0,\infty)$ | OOZ 試行の報酬予測精度 | $\text{Gamma}(2,0.3)$ |
| $\beta$ | $(0,\infty)$ | 逆温度 | $\text{Gamma}(2,3)$ |
| $c_{\text{black}}$ | $(-\infty,\infty)$ | 色バイアス | $\text{Normal}(0,2)$ |

**自由パラメータ数は4**で `q_learning_ooz_map` および `directional_q_learning_map` と同一．AIC/BIC の直接比較が公平に行える．旧 B-i では $h$ が厳密に識別不能で実効パラメータが1〜2個に潰れていたため比較が成立しなかったが，本設計ではその問題は生じない．

$\sigma$ は旧仕様の学習率 $\alpha$ の役割を担うが，$\alpha$ と違って**生成モデル上の意味を持つ**（報酬観測の精度）ため，$\sigma_1>\sigma_0$ という予測が仮説として直接読める．

**固定値**：

| 記号 | 既定 | 意味 |
|---|---|---|
| $M$ | 360 | $\psi$ グリッド分割数．$1^\circ$ 刻みで，刺激角度が整数度なので誤差なし |
| $\kappa_g$ | 4.0 | 般化幅（半値幅 $\approx 34^\circ$）．課題の真の帯幅 $45^\circ$ を与えないための緩い値 |
| $\epsilon$ | 0.0 | 信念の忘却＝予測ステップ．既定は忘却なし |

$\kappa_g$ または $\epsilon$ を自由化する場合は1つずつ緩め，パラメータリカバリを再確認する．

> **報酬の量子化について**：`reward_points` は整数（0〜10点）なので $r_t$ は $\{0,0.1,\ldots,1.0\}$ の11値をとる．厳密を期すなら $\mathcal{N}_{[0,1]}$ を各点の区間で積分した離散分布に置き換える．$\sigma_t \gtrsim 0.1$ ではほぼ差が出ないため既定では切断正規のまま扱い，$\sigma$ の推定値が $0.05$ を下回る参加者が出た場合のみ離散版で再確認する．

## B.7 対数事後と推定手続き

$$\log P(\boldsymbol{\theta}\mid\text{data}) \propto \sum_t \log P(a_t\mid b^-_t, o_t) + \sum\log P(\text{prior})$$

疑似コード（1参加者）：

```text
入力: theta_white[t], theta_black[t], a[t], theta_rep[t], r[t], ooz[t]
      （target_group / session_rotation は使わない！）
固定: M, kappa_g, eps
パラメータ: sigma_0, sigma_1, beta, c_black

psi  = linspace(0, 2*pi, M, endpoint=False)
logb = {white: zeros(M), black: zeros(M)}      # 一様事前（対数, 非正規化）
loglik = 0

for t in range(T):
    # ---- (i) 予測ステップ: psi は不変なので恒等写像（eps>0 なら忘却） ----
    for c in (white, black):
        if eps > 0:
            b = normalize(exp(logb[c] - max(logb[c])))
            logb[c] = log((1-eps)*b + eps/M)

    # ---- 選択: 報酬を見る前の信念で「払われる確率」を周辺化 ----
    for c in (white, black):
        b_c     = normalize(exp(logb[c] - max(logb[c])))
        p_pay_c = exp(kappa_g * (cos(theta_c[t] - psi) - 1))   # 長さ M, 値域 (0,1]
        pi_c    = sum(b_c * p_pay_c)                           # スカラー確率

    dq      = clip(beta * (pi_black - pi_white) + c_black, -500, 500)
    p_black = sigmoid(dq)
    loglik += log((p_black if a[t]==black else 1-p_black) + 1e-300)

    # ---- (ii) 補正ステップ: 報告した色の信念のみベイズ更新 ----
    sig      = sigma_0 if ooz[t]==0 else sigma_1
    ae       = wrap180(theta_rep[t] - theta_{a[t]}[t])         # 度
    r_pay    = max(0, 1 - abs(ae)/50)                          # psi に依らない
    r_nopay  = 0
    logA     = log_trunc_normal_pdf(r[t], r_pay,   sig, lo=0, hi=1)
    logB     = log_trunc_normal_pdf(r[t], r_nopay, sig, lo=0, hi=1)

    p_pay    = exp(kappa_g * (cos(theta_{a[t]}[t] - psi) - 1))
    logL     = logaddexp(log(p_pay) + logA, log1p(-p_pay) + logB)   # 長さ M

    logb[a[t]] += logL
    logb[a[t]] -= max(logb[a[t]])                              # 数値安定化

return loglik + log_prior(sigma_0, sigma_1, beta, c_black)
```

MAP 推定は既存モデルと同じく `scipy.optimize.minimize`（L-BFGS-B）＋グリッド初期値で負の対数事後を最小化する．1試行あたり長さ $M=360$ のベクトル演算が数回なので，48試行では既存モデルと同等のコスト．

> **`p_pay` が厳密に 0 にならないこと**：$p^{\text{pay}}(\psi)=\exp[\kappa_g(\cos\Delta-1)]$ は最小でも $e^{-2\kappa_g}$（$\kappa_g=4$ で $3.4\times10^{-4}$）なので $\log(1-p)$ も $\log p$ も有限に保たれ，信念が特定の $\psi$ をゼロで潰し切ることがない．これが暗黙のうちに「参加者は自分の推定を完全には確信しない」という緩和として働き，理想観測者（§B.10）との差を生む要因のひとつになる．

MAP 推定は既存モデルと同じく `scipy.optimize.minimize`（L-BFGS-B）＋グリッド初期値で負の対数事後を最小化する．$M=360$ のグリッド演算は 48 試行では無視できるコスト．

> **2種類の角度の使い分け**：本モデルは刺激の運動方向と報告方向を**別の役割で**使う．混同しないこと．
>
> | 角度 | どこで使うか | なぜ |
> |---|---|---|
> | $\theta_{a_t,t}$（刺激の運動方向） | $p^{\text{pay}}(\psi)=\exp[\kappa_g(\cos(\theta_{a_t,t}-\psi)-1)]$ | 潜在 $\psi_c$ は「色 $c$ の運動方向が**どこにあれば**払うか」を表す量だから |
> | $\theta_{\text{rep},t}$（報告方向） | $\hat r^{\text{pay}}_t = \max(0,1-\lvert\theta_{\text{rep},t}-\theta_{a_t,t}\rvert/50^\circ)$ と $a_t$ の判定 | 払われた場合に**何点入るか**は報告の精度で決まるから |
>
> 旧仕様（近似尤度版）は報告方向を $a_t$ の判定にしか使っていなかったが，本設計では報酬の連続値をそのまま尤度に載せるため，$\theta_{\text{rep}}$ が予測報酬の計算に入る．§B.1(4) で指摘した「報酬の連続性を捨てている」問題はここで解消される．

## B.9 事後分析：信念軌跡と「暗黙学習」の定量化

- **信念エントロピー $H(b_t)$ の低下速度**：試行を通じて単調に下がるか，どの試行で下げ止まるか．
- **信念ピークと真の高報酬方向のずれ**：$|\text{belief\_peak}_c - \psi_c^\star|$ の試行推移．
- **ターゲット選択確率**：Route A と同形式で $p(\text{target})$ を再構成し，実データの前後半差分と照合．
- **急峻さの検定**：信念フィルタの特徴は「ある試行を境に反転する」段階的変化である．実データの群平均は最良1点分割での段差が $0.297$，試行順シャッフルの帰無値が $0.235$ とその差はわずか $+0.062$ で，**群レベルでは急峻な反転が見えない**．被験者単位で段差が有意な参加者が居るかを個別に検定し，居るなら Route A ではなく本モデルが支持される．

## B.10 規範ベンチマーク（行動モデルとは別扱い）

潜在を「報酬が出る方向」に置き，**生成構造（帯の幾何と報酬関数）を既知とする理想観測者**を別途構成する．これは参加者のモデルではなく，課題の情報構造を測る物差しである．行動へのフィッティングは行わず，自由パラメータを持たず，BIC 比較の対象にもしない．

実測値（online 61名）：

| 指標 | 値 |
|---|---|
| 1試行目の状態エントロピー | $1.000$ bit（どんな解き手でも上限 $0.5$ の正答率） |
| 3試行後 | $H<0.01$ bit，デコード精度 $100\%$ |
| 同定までの試行数（中央値） | 3 |
| 実際の参加者（48試行後） | ターゲット選択率 $0.625$ |

**この差（3試行 vs 48試行で $0.625$）が「参加者は構造を明示的に取り出せていない」ことの定量的証拠**であり，暗黙学習という主張の根拠になる．ベンチマークが無ければ，参加者の低成績が課題の不可能性によるのか構造抽出の失敗によるのかを区別できない．

なおこのベンチマークは潜在を $r$（セッション回転）と書いても「報酬が出る方向」と書いても，テンプレート固定下で1対1に対応するため数値は同一である．行動モデルと混同しないよう，後者の表現を用いる．

## B.11 拡張オプション

- **排他性の仮定**：片方の色が払うならもう片方は払わない，という構造を与えて非選択色の信念も更新する．情報量は増えるが，参加者がその構造を知っている前提になるので，主モデルには入れない．
- **知覚ノイズの分離**：現在の設計は運動方向 $\theta_{c,t}$ を**正確に知覚している**と仮定している（$\sigma$ が知覚ノイズも報酬則の粗さもまとめて吸収している）．コヒーレンス依存の von Mises 測定モデルを噛ませて $\theta$ の不確実性を明示すれば，両者を分離できる（Route C と接続）．
- **$\kappa_g$ の自由化**：参加者ごとの般化幅の個人差を見る．
- **報酬の離散化**：`reward_points` の11値に合わせて切断正規を離散分布に置き換える（§B.6 の注記）．$\sigma$ の推定値が小さい参加者でのみ影響する．

# Route C（補）：知覚的状態推定 ― ノイズあるドットから真方向を推定

「刺激の画像から状態を推定する」を最も素直に定式化する道．RDK ではコヒーレンスが低いほど運動方向の知覚が不確実になる．真方向 $\theta^\star$ を潜在，知覚 $\hat\theta$ を観測とした **円環上のベイズ推定（von Mises 測定モデル）**：

$$P(\hat\theta\mid\theta^\star) = \frac{1}{2\pi I_0(\kappa_{\text{obs}})}\exp[\kappa_{\text{obs}}\cos(\hat\theta-\theta^\star)],\qquad \kappa_{\text{obs}} = g\cdot(\text{coherence})$$

事前 $P(\theta^\star)$（学習した方向価値を事前に流用も可）と掛けて事後 $P(\theta^\star\mid\hat\theta)$ を得る．これは **円環版カルマンフィルタ**に相当し，Route A の価値計算に「知覚の不確かさ」を注入する拡張になる．

> **深層 encoder（画像→状態）が必要になるのはここだけ**：RDK 刺激は（方向, コヒーレンス, 色）で完全に記述できるため，生画像から CNN で学習しても復元されるのは結局この方向とコヒーレンスである．したがって **手作りの $\phi(\theta)$ ＋ コヒーレンス依存の $\kappa_{\text{obs}}$ が，学習 encoder と実質同等かつ識別性で優る**．画像を直接入れる意義は，コヒーレンス以外の未知の知覚手がかりを疑う場合に限られる．

## モデル評価（3ルート共通）

1. **パラメータリカバリ**：48試行・実刺激系列で人工データ生成 → MAP 推定 → 真値と比較（Pearson $\ge 0.7$）．Route B は $\sigma_1$（OOZ 試行が少ない参加者）と，$\kappa_g$/$\epsilon$ を緩めた場合の識別性に特に注意．**旧 B-i で起きたような「尤度がパラメータに対して平坦になる」縮退が無いことを，リカバリで必ず確認する**（$\sigma$ を変えて対数尤度が動くか）．
2. **モデル比較**：`q_learning_ooz_map`（オラクル）／Route A（directional）／Route B（方向の状態推定）を **同一の自由パラメータ数4** で BIC・AIC・交差検証対数尤度で比較．
   - **Route B が Route A / オラクル版と同等以上に当てはまれば**，「報酬が出る方向を推定しながら暗黙に学習する」という記述が，矛盾なく（オラクルなしで）データを説明できたと言える ―― これが本研究の主張の定量的裏づけになる．
3. **Route A と Route B を分ける行動シグネチャ**：両者は「エージェントにどれだけ構造の仮定を与えるか」の両端であり，予測される学習曲線の形が違う．

   | | 構造の仮定 | 予測される変化 |
   |---|---|---|
   | Route A | なし．円環上の価値関数を TD で育てる | 漸進的・緩やか |
   | Route B | 「払う方向が1つある」という parametric な形 | 信念が絞れた時点でシャープに変化 |

   群平均では急峻な反転が見えない（§B.9）ため，現時点では Route A 寄りに見える．**被験者単位で段差の有無を検定し，両モデルの当てはまりと対応づける**こと．
4. **事後予測チェック**：推定パラメータ＋実刺激系列で多数回シミュレーション → ターゲット選択率の試行推移が実データを95%区間に含むか．Route B は加えて信念軌跡の妥当性（エントロピー低下のタイミング）も確認．
5. **規範ベンチマークとの距離**：§B.10 の理想観測者は行動モデルと**同じ土俵に載せない**（フィットさせない，BIC に入れない）．参加者の成績との差そのものを結果として報告する．

## どのルートをいつ使うか（意思決定）

- **すぐ矛盾を消したいだけ** → Route A（既存 `directional_q_learning_map.py`）で十分．追加実装ゼロ．ただし報告角のフレーム修正（§記号の注意）は必須．
- **「暗黙に隠れ構造を推定する」現象を正面からモデル化したい**（本研究の主張の核） → **Route B**．`state_estimation_q_learning_map.py` の改修．**推奨**．
- **知覚ノイズ（コヒーレンス）を明示的に扱いたい** → Route C を Route A/B に足す．
- **課題の情報構造そのものを測りたい／参加者の成績を評価する物差しが要る** → §B.10 の規範ベンチマーク．行動モデルとは用途が別．

## 前提の確認事項（実装前に決める）

1. ~~**報酬パターンは何で決まるか**：色レジームか方向依存か~~ → **決着済み．方向依存**．報酬は方向帯（`W_H=[0,45]°` 等）とセッション回転で決まり，色ラベルはその帰結にすぎない（§B.1(5)）．
2. ~~**ブロック構造とハザード率**~~ → **決着済み．ブロック構造は存在せず（切替率 $0.532$，$I(z_t;z_{t-1})=0.003$ bit），ハザード率という概念自体を使わない**．潜在 $\psi_c$ はセッション内で不変．
3. **報酬観測ノイズ $\sigma$**：旧仕様では固定値（0.3）だったが，本設計では**自由パラメータ**（OOZ で分割）．報酬則からの予測 $\hat r^{\text{pay}}$ と実際の報酬のズレを吸収し，理想観測者からの隔たりを表す（§B.3.3）．
4. **選択に使う信念のタイミング**：必ず報酬観測前の $b^-_t$（§B.5 の因果注意）．
5. **般化幅 $\kappa_g$**：課題の真の帯幅 $45^\circ$ を与えないこと．既定 $4.0$（半値幅 $\approx 30^\circ$）から始め，必要なら自由化．
6. **報告角のフレーム**：`response_angle_rdk` を使う（`response_angle_css` は鏡映座標）．
