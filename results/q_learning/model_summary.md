# 状態あり Q 学習モデル：構成と評価まとめ

## 1. モデル概要

### 状態・行動の定義

| 変数 | 内容 |
|------|------|
| 状態 s | 報酬構造のパターン：s=0（白=ターゲット，Pattern B），s=1（黒=ターゲット，Pattern A） |
| 行動 a | 選択した色：a=0（白），a=1（黒） |
| 報酬 r | reward_points / 10 ∈ [0, 1]（ターゲット選択時：1〜10点，ディストラクター選択時：0点） |

### Q 値テーブル

2状態 × 2行動の Q テーブルを保持する。初期値はすべて 0.5。

```
q[s, a] :  s ∈ {0, 1},  a ∈ {0(白), 1(黒)}

初期値:
  q = [[0.5, 0.5],   # state=0 (white=target): [Q_white, Q_black]
       [0.5, 0.5]]   # state=1 (black=target): [Q_white, Q_black]
```

### Q 値の更新則（Rescorla-Wagner）

選択した行動 a のみ更新する。

```
q[s, a] ← q[s, a] + α × (r − q[s, a])
```

- **α（学習率）**：0〜1。大きいほど直近の報酬を強く反映する。

---

## 2. 選択確率の定義

### 基本モデル（c_black なし）

「黒 vs 白」の log-odds を基準に softmax を計算する。

```
dq = β × (q[s, 1] − q[s, 0])

state=0 (白=ターゲット):  P(target) = P(白) = sigmoid(−dq) = 1 / (1 + exp(dq))
state=1 (黒=ターゲット):  P(target) = P(黒) = sigmoid(+dq) = 1 / (1 + exp(−dq))
```

- **β（逆温度）**：0〜∞。大きいほど Q 値の差を鋭く選択に反映する。

### 拡張モデル（c_black あり）

色バイアス項 c_black を log-odds に加算する。

```
dq = β × (q[s, 1] − q[s, 0]) + c_black

state=0 (白=ターゲット):  P(target) = 1 / (1 + exp(dq))
state=1 (黒=ターゲット):  P(target) = 1 / (1 + exp(−dq))
```

- **c_black**：−∞〜+∞。正で黒選好，負で白選好（状態に依存しない色バイアス）。

#### c_black が必要な理由

ディストラクター報酬は常に 0 であるため，Q[distractor] は試行を重ねるにつれて 0 へ収束する。
一方，Q[target] は正の報酬を受けるため常に Q[target] ≥ Q[distractor] ≈ 0 が成立し，
**基本モデルでは P(target) が構造的に 0.5 を下回れない**。
ターゲット選択率がチャンスレベル以下の参加者（強い色バイアスを持つ参加者）を説明するために
c_black が必要となる。

## 3. パラメータ推定（MAP 推定）

### 事前分布

| パラメータ | 事前分布 | 意味 |
|-----------|---------|------|
| α | Beta(2, 2) | 0〜1の範囲，中央付近に緩やかなピーク |
| β | Gamma(shape=2, scale=3) | 正の値，平均 6 程度 |
| c_black | Normal(0, 2) | バイアスなし（0）を中心に±2程度まで許容 |

### 最適化

グリッドサーチ × L-BFGS-B により局所最適を回避する。

- α の初期値：linspace(0.1, 0.9, 5)
- β の初期値：linspace(0.5, 10.0, 5)
- c_black の初期値：linspace(−2.0, 2.0, 5)（拡張モデルのみ）
- 合計：5×5=25 点（基本モデル），5×5×5=125 点（拡張モデル）

## 4. 適合度評価

### 指標の定義

| 指標 | 式 | 解釈 |
|------|---|------|
| Pseudo-R² (McFadden) | 1 − LL / LL_null，LL_null = n × log(0.5) | 0 = ランダム，1 = 完全予測 |
| AIC | −2 × LL + 2k | 小さいほどよい（k はパラメータ数） |
| BIC | −2 × LL + k × log(n) | AIC より複雑なモデルをより強くペナルティ |
| Choice accuracy | P(予測選択 = 実際の選択) | 0.5 = ランダム |

---

## 5. モデル比較結果（n = 54 名）

### 基本モデル（α, β：k = 2）

| 指標 | 平均 | 中央値 | SD | min | max |
|------|------|-------|----|-----|-----|
| log-likelihood | −26.37 | −29.37 | 8.01 | −34.16 | −3.34 |
| Pseudo-R² | 0.169 | 0.019 | 0.250 | −0.030 | 0.900 |
| AIC | 56.75 | 62.74 | 16.03 | 10.68 | 72.33 |
| BIC | 60.40 | 66.24 | 16.03 | 14.42 | 76.07 |
| Choice accuracy | 61.6% | 58.3% | 20.5% | 17.4% | 95.8% |

### 拡張モデル（α, β, c_black：k = 3）

| 指標 | 平均 | 中央値 | SD | min | max |
|------|------|-------|----|-----|-----|
| log-likelihood | −23.39 | −25.18 | 8.71 | −33.79 | −3.34 |
| Pseudo-R² | 0.264 | 0.198 | 0.270 | −0.024 | 0.900 |
| AIC | 52.77 | 56.37 | 17.42 | 12.67 | 73.57 |
| BIC | 58.25 | 61.81 | 17.44 | 18.29 | 79.19 |
| Choice accuracy | 73.2% | 75.8% | 14.0% | 46.8% | 97.9% |

### 改善量（拡張 − 基本）

| 指標 | 改善量 | 方向 |
|------|--------|------|
| log-likelihood | +2.99 | ↑ |
| Pseudo-R² | +0.095 | ↑ |
| AIC | −3.98 | ↓（良化） |
| BIC | −2.15 | ↓（良化） |
| Choice accuracy | +11.6pp | ↑ |

### 解釈

- **適合度**：log-likelihood の向上（+3.0）はパラメータ追加のペナルティ（AIC で +2，BIC で +log(n) ≈ +3.8）を上回り，AIC・BIC ともに拡張モデルが優位。
- **予測精度**：choice_accuracy が 61.6% → 73.2% に向上。基本モデルでは 25 パーセンタイルが 50%（ランダム予測と同等）だったのに対し，拡張モデルでは 59.8% まで改善。
- **pseudo-R² < 0 の参加者**：両モデルで最小値が負（≈ −0.03）となっており，Q 学習の枠組みでは説明しきれない行動パターンを持つ参加者が一定数存在することを示唆している。
- **結論**：色バイアス項（c_black）の追加は情報量基準・予測精度の両面で有効であり，特にターゲット選択率がチャンス以下の参加者の行動説明に大きく貢献している。
